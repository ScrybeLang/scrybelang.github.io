# Logical Operators

<hr>

Scrybe supports the logical operators `and`, `or`, `not`, and `in`. These work how you would expect, and have normal precendece. `in` works with both normal variables and lists.

 * `not 5 < 3` == `true`
 * `"e" in "world"` == `false`
 * `true and true and not false` == `true`
